# 📰 AI News Summarizer

A web application that fetches real-time top news headlines and generates a friendly AI-powered summary using Groq (LLaMA 3.3).

## 🚀 Demo

Click the button → get today's top 5 headlines → AI summarizes them in plain English.

## 🛠️ Built With

- **Python** — core language
- **Flask** — web framework
- **NewsAPI** — fetches real-time headlines
- **Groq (LLaMA 3.3)** — AI summarization
- **HTML, CSS, JavaScript** — frontend
